# PlanB Import Wizzard

Браузерное расширение для автоматического импорта данных пациентов из КТ-исследований **Orthanc DICOM** сервера в планирующую систему **PlanB**.

![Интерфейс PlanB  Import Wizzard](assets/screenshot.png)

---

## Возможности

* **Интеграция в UI PlanB**: Добавляет кнопку **Wizzard** в верхнюю панель прямо рядом с кнопкой «+ Добавить пациента».
* **Интеграция с Orthanc**: Получение списка КТ-исследований по REST API (`http://your-orthanc-server:8042`).
* **Автоматический парсинг DICOM-тегов**: Извлечение ФИО, ID пациента, даты рождения.
* **Автозаполнение формы**: Автоматическое открытие формы PlanB и занесение данных в соответствующие поля.
* **Быстрый поиск**: Фильтрация исследований по ФИО, ID или дате прямо в интерфейсе Wizzard.

---

## Совместимость

Расширение протестировано и гарантированно работает на конфигурации:
* **Версия сервера PlanB**: `2.8.8`
* **Версия клиента PlanB**: `2.8.5`

## Установка в браузер (Opera / Chrome / Edge)

1. Клонируйте или скачайте репозиторий:
   ```bash
   git clone https://github.com/Flacozyabra/PlanB_Import_Wizzard.git
   ```
2. Откройте страницу расширений в браузере:
   * **Opera**: `opera://extensions`
   * **Chrome**: `chrome://extensions`
   * **Edge**: `edge://extensions`
3. Включите **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное»** (*Load unpacked*) и выберите папку репозитория.

---

## Инструкция по использованию

1. Откройте страницу пациентов в системе PlanB (`https://your-planb-server/patients`) и авторизуйтесь.
2. В верхней панели рядом с кнопкой **«+ Добавить пациента»** нажмите кнопку **«Wizzard»**.
3. В открывшемся окне найдите нужное КТ-исследование и нажмите **«Выбрать»**.
4. Нажмите кнопку **«+ Добавить пациента»** в панели PlanB.
5. Форма добавления пациента заполнится автоматически:
   * ФИО транслитерируется на русский язык и приводится к ВЕРХНЕМУ РЕГИСТРУ.
   * Автоматически заполняются ID пациента и Дата рождения.
6. Укажите пол и выберите лечащего врача из списка PlanB, затем нажмите **«Добавить»**.

## Настройки подключения

Параметры подключения к серверу Orthanc настраиваются индивидуально на странице параметров расширения (сохраняются локально в хранилище браузера):
* **URL**: Адрес вашего Orthanc сервера (например, `http://192.168.5.100:8042`).
* **Логин**: Логин для доступа к REST API Orthanc.
* **Пароль**: Пароль пользователя Orthanc.

Для открытия страницы настроек:
- Перейдите на страницу расширений в браузере (`opera://extensions` / `chrome://extensions`).
- Нажмите **«Параметры»** под карточкой расширения или кликните правой кнопкой мыши по значку расширения в панели управления ➔ **Параметры**.
