# PlanB Orthanc Wizzard ✨

Браузерное расширение (Manifest V3) для автоматического импорта данных пациентов из КТ-исследований **Orthanc DICOM** сервера в планирующую систему **PlanB**.

![Интерфейс PlanB Wizzard](assets/screenshot.png)

---

## 🚀 Возможности

* 🪄 **Интеграция в UI PlanB**: Добавляет кнопку **Wizzard** в верхнюю панель прямо рядом с кнопкой «+ Добавить пациента».
* 🏥 **Интеграция с Orthanc**: Получение списка КТ-исследований по REST API (`http://your-orthanc-server:8042`).
* 📋 **Автоматический парсинг DICOM-тегов**: Извлечение ФИО, ID пациента, даты рождения, пола и описания КТ.
* ⚡ **Автозаполнение формы**: Автоматическое открытие формы PlanB и занесение данных в соответствующие поля с подсветкой.
* 🔍 **Быстрый поиск**: Фильтрация исследований по ФИО, ID или дате прямо в интерфейсе Wizzard.

## 🛠️ Установка в браузер (Opera / Chrome / Edge)

1. Клонируйте или скачайте репозиторий:
   ```bash
   git clone https://github.com/Flacozyabra/PlanB_Import_Wizzard.git
   ```
2. Откройте страницу расширений в браузере:
   * **Opera**: `opera://extensions`
   * **Chrome**: `chrome://extensions`
   * **Edge**: `edge://extensions`
3. Включите **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное»** (*Load unpacked*) и выберите папку репозитория.

---

## 📖 Инструкция по использованию

1. Откройте систему PlanB (`https://your-planb-server/patients`) и авторизуйтесь.
2. В верхней панели рядом с кнопкой **«+ Добавить пациента»** нажмите **«Wizzard»**.
3. В открывшемся окне найдите нужное КТ-исследование и нажмите **«Выбрать»**.
4. Расширение откроет форму добавления пациента в PlanB и заполнит поля.
5. Выберите врача из выпадающего списка PlanB и нажмите кнопку сохранения.

---

## ⚙️ Настройки подключения

Параметры Orthanc настраиваются индивидуально для каждого пользователя в параметрах расширения:
* **URL**: `http://<IP_ИЛИ_ХОСТ_ORTHANC>:8042`
* **Логин**: `orthanc` (по умолчанию)
* **Пароль**: `orthanc` (по умолчанию)

Для изменения параметров нажмите **«Параметры»** под расширением на странице `opera://extensions` или кликните правой кнопкой по значку расширения -> *Параметры*.
